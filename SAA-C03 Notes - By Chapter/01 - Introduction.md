## 03 - Creating an AWS Account
(src: 01/03-Creating an AWS Account)
- Use "Sign up" advanced flow; enter root user email and account name; verify email.
- Password: min 8 characters, at least 3 of uppercase, lowercase, numbers, non-alphanumeric. Store it safely.
- Account plans: **Free** vs **Paid**. Both start with about **$100 credit**, up to **$200** total. Free plan: no charge, account closes automatically when credits run out. Paid plan: for production workloads; charged to the card beyond credits.
- Card is required even on Free plan (identity verification/fraud prevention); **$1** verification charge is refunded. Then phone verification and **Basic support** (free).
- Sign in again via "Sign in to console" -> root user email.

[verify] Free plan: "account closes automatically when credits run out"; "$100 credit, up to $200 total".
> [!warning] Correction [note]
> AWS docs: new accounts get $100 credits plus up to $100 more for activities; the Free plan also **ends after six months** or when credits are used, whichever comes first; the account then closes, content is retained 90 days, and you can upgrade to Paid within that window. Source: [Choosing a plan](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/free-tier-plans.html)

### Hands-on steps
1. AWS site -> Create account -> choose the advanced sign-up option [screen action].
2. Enter root email + account name, verify email, set password.
3. Choose Free plan; enter contact info and card; verify phone.
4. Choose Basic support; wait for activation email; sign in as root user.
